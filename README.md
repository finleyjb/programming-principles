# Programming principles for agents

Programming principles is a set of coding skills for agents. These skills are:

- **Timeless**: These principles have been true for over 20 years, and they will be true for the next 20 years
- **High-quality**: This is the really important stuff your agent needs to know when they're writing code
- **Reasonably opinionated**: I wrote these from a strong point of view, but these skills allow for disagreement
